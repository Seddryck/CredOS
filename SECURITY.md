# Security policy

CredOS has no published release yet. Security fixes currently target `main`.

Use GitHub private vulnerability reporting for
[Seddryck/CredOS](https://github.com/Seddryck/CredOS/security/advisories/new)
when available. If private reporting is unavailable, request a private reporting
channel from the maintainer before sharing sensitive details. Do not disclose
exploitable vulnerabilities or credentials in public issues.

Include the affected revision, relevant files, reproduction steps, impact, and
any configuration needed to reproduce the problem. Remove secrets from examples.
